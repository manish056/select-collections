# Select Collections, Inc. - Delinquent Account Recovery Prediction

This project was created as part of a Business Analytics initiative to help **Select Collections, Inc.** predict potential recovery amounts (`totalpay`) from delinquent accounts using machine learning and data visualization.

## 📊 Project Summary

We used a dataset of 3,570 delinquent accounts and applied machine learning regression models to estimate expected recovery. The results help prioritize collection efforts and improve overall recovery strategy.

## 🔍 Files in This Repository

| File | Description |
|------|-------------|
| `Project_file.ipynb` | Jupyter Notebook containing the machine learning workflow (EDA, feature engineering, modeling, and evaluation). |
| `powerbi (1).pbix` | Power BI dashboard for visualizing model insights and account-level trends. |

## ⚙️ Tools & Technologies

- **Python** (Jupyter Notebook)
  - pandas, numpy, scikit-learn, xgboost, matplotlib
- **Power BI** for dashboard visualization

## 📈 Model Performance

The best-performing regression model was selected based on RMSE (Root Mean Squared Error), achieving optimized predictions for `totalpay`.
